# Anixart Desktop — установщики

Это публичный репозиторий **релизов** неофициального приложения Anixart Desktop для Windows и macOS. Исходный код приложения здесь не публикуется.

## Скачать приложение

- **Последняя стабильная версия:** https://github.com/MurrRchalka/Anixart/releases/latest
- **Все версии (включая предварительные):** https://github.com/MurrRchalka/Anixart/releases

В каждом опубликованном релизе ожидаются следующие файлы:

| Платформа | Файл |
| --- | --- |
| Windows | `Anixart-Desktop-vX.Y.Z-Windows-Setup.exe` — установщик |
| macOS (Apple Silicon и Intel) | `Anixart-Desktop-vX.Y.Z-macOS-Universal.dmg` — образ приложения |
| Проверка загрузки | `SHA256SUMS.txt` — контрольные суммы установщиков |

Версии помечаются тегами `vX.Y.Z`. Если страница релизов пуста, первая версия ещё не опубликована.

**Важно:** наличие установщика в Releases само по себе не гарантирует наличие встроенного автоматического обновления. До завершения реализации и проверки механизма обновлений новые версии устанавливаются через скачивание соответствующего релиза.

Проект не является официальным приложением или продуктом Anixart.
